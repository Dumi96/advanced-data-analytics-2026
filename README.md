## Project 01 – Retail Sales Intelligence

### Business Objective

Develop a retail analytics solution to understand sales performance, product profitability, customer purchasing behaviour, and business performance using relational data and SQL.

### Technology Stack

- PostgreSQL – Relational database and analytical queries
- SQL – Data retrieval, transformation, aggregation, and analysis
- Python – Planned for data cleaning and exploratory data analysis
- Power BI – Planned for interactive business dashboards
- Git & GitHub – Version control and project documentation

### Database Structure

The project currently contains four relational tables:

| Table | Purpose |
|---|---|
| customers | Customer information |
| products | Product details, selling prices, and costs |
| orders | Customer order information |
| order_items | Individual products and quantities within orders |

### Implemented Analysis

**1. Product Profitability Analysis**

Analyses product sales, revenue, cost, and profit using SQL joins, aggregations, and grouping.

Current sample results:

- Total revenue: LKR 373,000
- Total cost: LKR 290,000
- Total profit: LKR 83,000
- Highest-profit product: Laptop

**2. Customer Spending Analysis**

Identifies customer purchasing behaviour, completed orders, total items purchased, and customer spending.

Current sample findings:

- Highest-spending customer: John Silva
- Customer spending: LKR 270,000
- Completed orders: 4

*All figures are based on synthetic sample data created for learning purposes.*
